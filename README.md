# SRCE kartice

Jednostavna GitHub Pages prezentacija za **SRCE - Set za emocionalni razvoj dece**.

SRCE je set od 62 ilustrovane kartice koje pomazu deci da prepoznaju, razumeju i izraze emocije kroz razgovor, igru i podrsku odraslih.

## Sta je na sajtu

- Predstavljanje proizvoda SRCE kartice
- Primeri pravih kartica: Radost, Uzbudjenje, Ljubav i Poverenje
- Lista emocija koje kartice pokrivaju
- Uputstvo kako koristiti kartice sa decom
- Fokus na autorku Jovanu Cieslak, njenu ekspertizu i razlog nastanka kartica
- Brza kupovina preko Stripe linkova
